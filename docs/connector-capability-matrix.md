## Changes in this branch

- Miro now serves the full retained official REST package and uses the exact saved eleven-scope set. Its malformed group-delete route is removed before import; the pinned compiler now finds 181 operations with none skipped. Its organization-scope mismatch is recorded above.
- Zendesk now serves every operation in its official Support API OpenAPI document, with all mutations approval-gated, the `read`, `write` and `impersonate` OAuth scopes, and the vendor primary logo.
- Atlassian's saved classic-scope count does not match the current official Jira/JSM documentation. Its five-read source remains unchanged until the permitted request and API-operation coverage can be verified.
- AWS remains the explicit large connector gap. The other rows report source coverage and provider limits, not live access acceptance.
